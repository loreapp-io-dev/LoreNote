## [0.2.0] - 2026-01-30

### Added
- GitHub Actions for automated multi-platform releases
- AGPLv3 license
- Comprehensive developer documentation in README
- Release automation script (`release.sh`)
- Automatic version number updates

### Changed
- Updated `tauri-plugin-dialog` to v2.6.0 for compatibility

### Fixed
- Version mismatch between npm and Rust packages

## [0.1.0] - 2026-01-24

### Added
- Initial release
- JSON Schema-driven rendering engine (V8)
- Multi-vault support
- Block-based editor with slash commands
- Wiki links with hover preview
- Light/Dark theme
- Chinese/English i18n
- Developer tools (Schema editor, template library, debug console)
- Multiple block types (text, heading, list, table, media, etc.)
